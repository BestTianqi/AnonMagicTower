# 《迷途返场》主线修订

这是一条爱音／素世的原创同人 AU 感情线，不是官方剧情复述。游戏中的 31 个场景均已修订，实际文本、表情及进度分支在 `UI/StoryScript.h`。

## 主线节奏

| 段落 | 情节与关系推进 |
| --- | --- |
| 1–3 层 | 排练后素世先行离开。半句「下次排练，我……」将爱音引入塔中。素世的防备不是单纯反派宣言，而是害怕又一次等不到“下次”。 |
| 5–10 层 | 拨片上的防滑胶、谱架上的练习便签呈现素世平时的关心。爱音开始以具体练习回应，而不是反复保证永远。海铃对白围绕观察和节奏。 |
| 15–29 层 | 米歇尔看穿爱音藏起的伤，爱音答应请饮料。开暗道时米歇尔被机关带走，折返营救成为两人关系的实际推进。 |
| 32–35 层 | 小素世质疑承诺；对白根据是否已经营救米歇尔变化。35 层米歇尔显露暗墙，并约定五十层见面，不提前揭面。 |
| 40–49 层 | 童年影子被自己的防备围困；爱音不再只应对“笑着的素世”。假魔王重复理想答案，封印切断的是舞台幻象的力量。 |
| 50 层 | 米歇尔亲自摘下头套，解释舞台影子，承认伤害而不把责任全推给塔。爱音告白，素世在战后说完留言并作出回应。尾声回到排练室与群消息。 |

## 口吻与表现

- 爱音保留爱吐槽、嘴硬又会行动的一面。例：「怕啊。所以跑得累死了。先伸手，你的袖子卡住了。」
- 素世不是一路重复说教：先回避，再承认相互矛盾的想法，最后主动提出“多陪我一会儿”。
- 终幕不以胜利强制换取感情。素世回应：「我也喜欢你。不是想让你留下才这么说。」
- 心负责接住低落，海铃提醒看清当前局面，友希那强调站稳自己的位置，香澄保留对声音的好奇，不让所有配角成为同一种劝告者。
- 爱音、校服素世、魔女素世、幼年素世和米歇尔根据单句情绪使用现有立绘。对话换人时保持左右角色身份；旁白不凭空换成素世。已有专属 CG 仍全窗显示。

## 探索顺序兼容

- 32 层：尚未经历抓捕、已抓捕未救出、已救出分别处理；未救出时提示二层右下角与中级守卫。
- 50 层：完成 35 层约定、只认识米歇尔、未见过米歇尔分别处理。不会因走捷径就虚构玩家已经营救或约定过。
- 使用既有 `anon_soyo_scene_*` 已看标记，不新增存档字段，不清空旧标记。旧存档中看过的片段不会为了展示新台词再次强播；想完整体验可以另开新游戏并使用新的存档槽。

## 与魔塔机制的边界

地图、数值、触发位置、战斗先攻与奖励未改。五层／九层对白使用爱音拨片／素世谱架，保留铁剑／铁盾的原版对应提示。十层仍清理八名侧翼守卫，三十三层仍清理四角，三十五层仍需撞开显露的暗墙，四十九层仍需击败四名魔法警卫完成封印。

## 验证方式

`mota_story_script_tests` 检查 31 场对白、16 种进度组合、关键提示、提前泄底、每页长度、资源引用和表情区分。`mota_mainwindow_input_tests --story-only` 验证开场引导、35 层对话对象、50 层揭面及一次性标记存取；这个限定入口不运行依赖真实 AppData 的即时存档测试，测试数据在工作目录内的临时目录中清理。
