# 原版 50 层数据映射

本版本以 [Sin365/MoTaForPSVita](https://github.com/Sin365/MoTaForPSVita) 的完整 50 层重制数据作为坐标与数值校准来源。`data/classic50_map.txt` 由其 `mapinfo.txt` 机械转换而来，保留 1–50 层全部 3744 条静态对象记录。Unity 坐标 `(x, y)` 映射到本项目 15×15 地图的 `(x + 7, 7 - y)`，原版 11×11 区域因此位于第 2–12 行、列。

怪物 ID 1–34 在 `Entities/MonsterDB.h` 中保持原版 HP、攻击、防御和金币，仅将名称与头像替换为 MyGO!!!!!、Ave Mujica、梦限大みゅーたいぷ及薇欧拉的主题形态。ID 1–32 使用 `monster.md` 的本体/SP 映射；ID 33、34 分别映射为“长崎素世·幻影”和“长崎素世·本体”。

原版第三钥匙槽是黄钥匙。为了兼容既有存档的数值布局，代码内部仍沿用旧枚举 `KeyType::Green` / `Tile_DoorGreen`，游戏显示和新地图行为均已改为黄钥匙/黄门。

前三层序章按原版流程处理：3层下楼梯右侧第一格触发昏迷并把主角送回2层小偷旁；小偷分两次对话，先说明牢房处境，再提示铁剑在5层、铁盾在9层；3层的怪物手册 NPC 保留在原始位置。

10 层不走普通清怪判定：从红门走到八幡海铃前一格会触发她退到最上方、左右花门取消、上下花门封锁；地图内侧第三、第四排（坐标行4、5）的八只侧翼骷髅保持原位，不播放移动。击败这八只侧翼怪后上下机关门开启，击败八幡海铃后在地图正中间最下方生成奖励楼梯。铁门仍按原版配置的指定守卫组处理；48层左上角额外生成一只藤都子SP，击败她后解锁圣剑房花门（未触发事件前仍可用镐破坏）。编辑器自定义楼层未配置事件时则采用清空本层怪物后开门的通用规则；经典塔楼层若出现未配置机关门则保持关闭，避免错误放行。

10、20、40层阶段 Boss 的掉落统一为原版奖励组：每层各生成 3 个红宝石、3 个蓝宝石、3 个黄色钥匙和 3 个本阶段大血瓶。主题显示名分别为舞台红宝石、舞台蓝宝石、黄色Live票和爱音能量饮。奖励生成在 Boss 周围；10、20层在地图正中间最下方生成向上楼梯，40层在地图正中间最上方生成向上楼梯。奖励只生成一次，重复与已清除的 Boss 不会重复发放。

39层对称飞行器不是对话奖励：打开左上房间12点方向与3点方向的两扇黄门后，中心格生成对称飞行器（主题名“Mujica镜面舞台票”，可左右对称移动3次）；40层 Boss 区入口的原版花门已改为红门，按红钥匙规则开启。49层假魔王一开始就以 8000/5000/1000 的满属性出现，必须先击败其上下左右四名中央魔法警卫，封印才会生效并将属性削弱为 800/500/100；再击败剩余四名斜角魔法警卫，最后挑战假魔王。

道具工厂和经典地图已覆盖原版道具：黄/蓝/红钥匙、万能钥匙、小/大血瓶、红/蓝宝石、飞行魔杖、记事本、镐、冰冻魔法、炸弹、十字架、圣水、幸运金币、上/下楼器、铁剑/盾、银剑/盾、骑士剑/盾、圣剑/盾、神圣剑/盾，以及可由 NPC/编辑器放置的对称飞行器、地震卷轴和屠龙匕。剑盾数值为 +10/+20/+40/+50/+100；宝石和药水按每十层的经典档位计算。属性商店价格按全局购买次数使用二阶等差数列 `20、40、80、140、220……`，次数跨楼层共享；生命购买加成为全局购买序号×100（首次 +100），攻击/防御增量按所在楼层商店独立计算；每个商店 NPC 只能完成一次交易。十字架对吸血鬼/兽人翻倍，屠龙匕对魔龙翻倍，圣盾系列免疫法师/巫师/魔法攻击，冰冻魔法可冻结下一格岩浆，飞行魔杖支持 1–50 层传送，对称飞行器支持三次左右对称传送。所有新增状态均写入 `EXTRA` 存档字段，并兼容旧存档。

## MyGO / Ave Mujica 本地化命名

原版功能名称只作为兼容别名保留，游戏内显示统一采用乐队主题：攻击装备依次为“爱音拨片、立希鼓棒、乐奈猫爪、灯的麦克风、睦的贝斯”，防具依次为“素世谱架、海铃节拍器、初华舞台耳返、祥子黑色乐谱、Mujica终幕面具”。补给、钥匙与特殊道具也替换为现场补给、Live票、成员随身物和舞台道具；旧地图与旧存档中的“铁剑/神圣盾/小血瓶”等名称会自动归一到新的显示名。
