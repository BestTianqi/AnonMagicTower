# 原版 50 层数据映射

本版本以 [Sin365/MoTaForPSVita](https://github.com/Sin365/MoTaForPSVita) 的完整 50 层重制数据作为坐标与数值校准来源。`data/classic50_map.txt` 由其 `mapinfo.txt` 机械转换而来，保留 1–50 层全部 3744 条静态对象记录。Unity 坐标 `(x, y)` 映射到本项目 15×15 地图的 `(x + 7, 7 - y)`，原版 11×11 区域因此位于第 2–12 行、列。

怪物 ID 1–34 在 `Entities/MonsterDB.h` 中保持原版 HP、攻击、防御和金币，仅将名称与头像替换为 MyGO!!!!!、Ave Mujica、梦限大みゅーたいぷ及薇欧拉的主题形态。ID 1–32 使用 `monster.md` 的本体/SP 映射；ID 33、34 分别映射为“长崎素世·幻影”和“长崎素世·本体”。

原版第三钥匙槽是黄钥匙。为了兼容既有存档的数值布局，代码内部仍沿用旧枚举 `KeyType::Green` / `Tile_DoorGreen`，游戏显示和新地图行为均已改为黄钥匙/黄门。

机关门按原版事件门处理：花门/铁门不消耗钥匙。2 层铁门在中级卫兵清除后开启；10 层从红门走到八幡海铃前一格会触发她退到最上方、上下位置锁定和六只侧翼骷髅包围，清完包围怪后花门及锁门开启，击败八幡海铃后在地图正中间最下方生成奖励楼梯；49 层则在指定守卫事件后推进 Boss 战。48 层圣剑房保留原版“损坏花门”设定，清怪不会开门，只能用镐破坏或通过传送绕过；编辑器自定义楼层未配置事件时则采用清空本层怪物后开门的通用规则。

道具工厂和经典地图已覆盖原版道具：黄/蓝/红钥匙、万能钥匙、小/大血瓶、红/蓝宝石、飞行魔杖、记事本、镐、冰冻魔法、炸弹、十字架、圣水、幸运金币、上/下楼器、铁剑/盾、银剑/盾、骑士剑/盾、圣剑/盾、神圣剑/盾，以及可由 NPC/编辑器放置的对称飞行器、地震卷轴和屠龙匕。剑盾数值为 +10/+20/+40/+50/+100；宝石和药水按每十层的经典档位计算。十字架对吸血鬼/兽人翻倍，屠龙匕对魔龙翻倍，圣盾系列免疫法师/巫师/魔法攻击，冰冻魔法可冻结下一格岩浆，飞行魔杖支持 1–50 层传送，对称飞行器支持三次左右对称传送。所有新增状态均写入 `EXTRA` 存档字段，并兼容旧存档。

## MyGO / Ave Mujica 本地化命名

原版功能名称只作为兼容别名保留，游戏内显示统一采用乐队主题：攻击装备依次为“爱音拨片、立希鼓棒、乐奈猫爪、灯的麦克风、睦的贝斯”，防具依次为“素世谱架、海铃节拍器、初华舞台耳返、祥子黑色乐谱、Mujica终幕面具”。补给、钥匙与特殊道具也替换为现场补给、Live票、成员随身物和舞台道具；旧地图与旧存档中的“铁剑/神圣盾/小血瓶”等名称会自动归一到新的显示名。
