# Map and gameplay tile roster

Generated pixel-art atlases with a removable chroma-key background converted to alpha PNGs.

| Atlas | Contents |
|---|---|
| `images/tiles/dungeon_tiles.png` | walls, floors, doors, stairs, portal, crystals, chest, torch |
| `images/tiles/doors_stairs.png` | colored doors, boss gate, stairs, teleport and save-point variants |
| `images/tiles/props.png` | chests, potions, stat pedestals, instruments, banners, keys and switches |
| `images/tiles/effects.png` | lock glows, healing, teleport, sigils, soundwaves, glitch, elemental and victory effects |

Each atlas is intended as a source sheet for extracting 64×64 tiles or objects. Runtime tile registration is left unchanged in this art pass.
