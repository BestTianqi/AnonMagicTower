# Game background roster

Six background plates generated for the first playable tower pass. They share a pixel-art anime RPG treatment and leave readable negative space for map or battle UI.

| Use | File |
|---|---|
| Tower hub / central lobby | `images/backgrounds/tower_hub.png` |
| MyGO!!!!! live-house stage | `images/backgrounds/mygo_stage.png` |
| Ave Mujica gothic theater | `images/backgrounds/mujica_theater.png` |
| 梦限大みゅーたいぷ dream room | `images/backgrounds/yumemita_dream.png` |
| Nagasaki Soyo final boss chamber | `images/backgrounds/boss_soyo.png` |
| Music-themed item shop | `images/backgrounds/shop_music.png` |

These are scene plates rather than tile atlases; map collision and floor tiles remain separate so the existing tower renderer can layer them without changing runtime code in this pass.
