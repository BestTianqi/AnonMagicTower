# 魔塔 (Magic Tower)

基于 Qt6/C++17 的经典魔塔游戏，内置地图编辑器、修改器和自定义素材支持。

## 编译运行

### 依赖

- **CMake** 3.16+
- **Qt 6.5+** (Widgets 模块)
- 支持 C++17 的编译器 (MinGW / MSVC / GCC / Clang)

### 构建

```bash
cmake -B build
cmake --build build
./build/mota   # Windows: build\mota.exe
```

## 游戏操作

| 按键   | 功能            |
| ------ | --------------- |
| 方向键 | 移动            |
| 鼠标   | 菜单/对话框操作 |

右侧面板显示玩家属性（HP、ATK、DEF、金币、钥匙），左侧面板显示当前楼层所有怪物。

道具可通过背包打开使用，被动道具自动生效。

## 地图编辑器

从主菜单或游戏内均可打开地图编辑器。支持：

- 放置/擦除墙壁、地板、门、怪物、道具、NPC、商店、楼梯等
- 点击已放置的图块可编辑其属性（怪物数值、NPC 对话/交易、商店售价等）
- 导入/导出 `.map` 和 `.txt` 格式
- 测试游玩（从编辑器直接启动游戏）
- 玩家位置放置（Shift+点击放置玩家起点）

### .map 与 .txt 格式

`.map` 为二进制格式（紧凑），`.txt` 为文本格式（可读可手动编辑）。

推荐使用 `.txt` 格式编辑默认地图，路径：`map.txt`（构建时嵌入 exe）。

## 游戏机制

- **20 种怪物** 按楼层递进难度
- **战斗系统**: 伤害 = max(0, 攻击 - 防御)，吸收盾 +50 额外防御
- **门与钥匙**: 红/蓝/绿三种门，万能钥匙可开任意门 3 次
- **道具系统**:
  - 属性道具：生命药、武器、防具、金币
  - 特殊道具：眼镜（可以看到假墙）、破墙锤、上楼器/下楼器、临时护盾
  - 被动道具：企鹅玩偶（对特定敌人伤害减半）、抹茶芭菲（对特定敌人伤害减半）、幸运金币（金币翻倍）
- **商店**: 可购买生命药/武器/防具，价格递增
- **修改器**: 游戏内置，可随时调整属性或添加道具
- **存档**: 支持存档/读档（.txt 格式）

## 项目结构

```
mota/
├── main.cpp                 # 入口
├── Game/
│   ├── Game.h/cpp           # 核心逻辑（移动、战斗、楼层、序列化）
├── Entities/
│   ├── Player.h/cpp         # 玩家（属性、背包、钥匙）
│   ├── Monster.h/cpp        # 怪物
│   ├── MonsterDB.h          # 18 种怪物预设
│   ├── Items.h/cpp          # 道具（药水、武器、防具、钥匙等）
│   └── NPC.h/cpp            # NPC（对话、交易、奖励）
├── UI/
│   ├── MainWindow.h/cpp     # 游戏主窗口（HUD、背包、商店、修改器）
│   ├── MapWidget.h/cpp      # 地图渲染（图块/道具/怪物绘制）
│   ├── MapEditor.h/cpp      # 地图编辑器
│   ├── MenuWindow.h/cpp     # 主菜单
│   ├── ui_MainWindow.h      # 主窗口 UI 布局
│   └── ui_MenuWindow.h      # 菜单 UI 布局
├── images/                  # 图片素材（构建时嵌入 exe）
├── map.txt                  # 默认地图（构建时嵌入 exe）
├── resources.qrc            # Qt 资源文件
└── CMakeLists.txt
```

## 自定义素材

将 60×60 PNG 图片放入 `images/` 目录，文件名对应：

| 文件                                    | 用途                           |
| --------------------------------------- | ------------------------------ |
| `player.png`                          | 玩家                           |
| `npc.png`                             | NPC                            |
| `monster_01.png` ~ `monster_18.png` | 18 种怪物（按 MonsterDB 顺序） |

其他图块（墙壁、地板、门等）也可添加同名图片覆盖。构建后重新编译即可生效。
